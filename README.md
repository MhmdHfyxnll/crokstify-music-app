## Deskripsi Project

Crockstify adalah aplikasi saya berupa music streaming berbasis Flutter yang dirancang untuk memberikan pengalaman mendengarkan musik yang modern, sederhana, dan interaktif.
Aplikasi ini memiliki fitur utama seperti home dashboard, pencarian lagu, mini player, profile user, settings, login account, serta dark mode untuk meningkatkan kenyamanan pengguna.

---

## Fitur Utama

* Login Account User
* Home Dashboard Music App
* Search Song & Discovery
* Mini Player Music
* Profile & Settings User
* Dark Mode Feature
* Logout System
* Responsive UI Design
* Bottom Navigation Bar

---

## TeknIologi yang Digunakan

* Flutter
* Dart
* Visual Studio Code
* Shared Preferences
